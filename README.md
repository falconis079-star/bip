# Бип дома

Тап-игра для ВКонтакте. 10 уровней. После каждого уровня — шортс из группы https://vk.ru/robotbip

## Что уже стоит
- owner_id: -235726365
- 10 комнат по сюжету серии
- 3 жизни, очки, рекорд
- экран шортса после уровня
- заготовки VK Bridge: init, шаринг, группа, rewarded-реклама, покупка жизни

## Как открыть сейчас
Просто открой `index.html` в браузере телефона или компьютера.

## Как залить во ВК
1. Создай приложение-игру на https://dev.vk.com
2. Впиши App ID в `config.js`
3. Залей папку на хостинг статики ВК (`vk-miniapps-deploy`)
4. Для автоподгрузки 10 последних клипов лучше сделать крошечный сервер-прокси с ключом сообщества (право video). В клиент ключ не клади.
5. Пока ключа нет, после уровня открывается заглушка / группа, кнопка «Дальше» оживает через 5 секунд.
